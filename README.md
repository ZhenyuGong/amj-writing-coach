# AMJ Writing Coach

A Codex skill based on the seven-part *Publishing in AMJ* editorial series (2011–2012). It helps diagnose, plan, draft, and revise empirical management papers. The skill contains original synthesis and links to the source articles.

The repository also includes a [35-item inventory of AMJ's official From the Editors collection](amj-writing-coach/references/fte-collection.md), with [CSV](catalog/collection.csv) and [JSON](catalog/collection.json) metadata. This is a source catalog; full-text synthesis of the additional editorials is a later stage.

## Install

Copy `amj-writing-coach/` into your Codex skills directory, typically `~/.codex/skills/`, and restart Codex or start a new chat. Invoke it with `$amj-writing-coach` or ask for AMJ-oriented manuscript feedback.

## Sources and rights

See [the source index](amj-writing-coach/references/sources.md) for all seven DOIs and public PDF locations. The PDFs are kept locally in `papers/` for private study and excluded from Git. This repository does not redistribute the articles or claim affiliation with the Academy of Management.
